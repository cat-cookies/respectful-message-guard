公務人員有另行的安全衛生防護與申訴處理制度，不能只套用一般勞工程序。機關須設防護機制、採取立即保護措施，並依規定調查與決定。

一般場所性騷擾

主要法源：性騷擾防治法及其相關準則。

跟蹤騷擾

對特定人反覆或持續為違反其意願、與性或性別有關的監視、尾隨、威脅貶抑、通訊干擾、不當追求、寄送物品、散布名譽訊息或濫用個資，並使人心生畏怖、足以影響日常生活或社會活動，才進入跟蹤騷擾法制。

隱私、資訊安全與低耗能設計

文字仍在本機處理

網站沒有帳號、伺服器資料庫、雲端文字模型、分析追蹤或廣告程式。高風險語料、安全生成語料、轉移權重所需資料與小型領域神經語言模型都直接包在網站檔案內，目前包含 載入中。輸入文字與潤稿候選不會送到第三方文字 API。

工作內容也會被檢核

系統會另外檢查「陪酒／強制社交、疑似私人差事、明顯不合理工作目標、下班或休假持續待命、限制請假、要求不實紀錄、規避安全程序、性別化外貌要求」等工作內容風險。高風險要求不會被改寫成一段看似禮貌、實際仍不合理的命令。

三個步驟使用同一條資料流

步驟一的原始訊息會先拆成工作主題、客觀事實、要求行動、期限與原因／影響，並同步到步驟二供使用者確認／修正；步驟三再使用這份已確認內容生成訊息，同時保留原始訊息做完整風險掃描。人工修正過的欄位不會被後續自動抽取覆蓋。辱罵、羞辱、性意味、威脅與情緒施壓只進入風險層，不會直接進入輸出。

潤稿不是固定模板拼接

系統會依工作情境、對象、溝通強度與風格建立多條候選接龍路徑，再同時使用安全語料轉移機率、霸凌語料反向權重、詞彙政策與內嵌神經語言模型評估流暢度。只有通過風險與工作合理性檢核的高分候選才進入加權抽選，因此不是把欄位照順序硬接起來，也不會為了隨機而抽到低品質句子。

資料最小化

原始訊息與潤稿結果不寫入 localStorage、IndexedDB、Cookie 或檔案。只有你主動送出的「本機回饋詞／短片段與不OK／誤判次數」會存入 localStorage，用來計算這台瀏覽器的自訂權重；完整原始訊息不會因回饋功能被保存。另只有「本分頁是否略過法制說明」使用 sessionStorage。

網路使用範圍

文字處理所需的 JavaScript、兩個正式語料庫與模型權重全部隨 ZIP／GitHub Pages 一起部署，不會在執行時向 CDN 或模型網站下載檔案。本機啟動程式只建立 127.0.0.1 靜態網站，文字判斷仍在瀏覽器內完成。法律來源連結只有在使用者自行點擊時才會離開本站。

語音輸入另有瀏覽器層級限制

語音按鈕使用瀏覽器 Web Speech API 的繁體中文辨識，不使用會造成 phrases-not-supported 的實驗性詞組偏置。若瀏覽器已安裝 zh-TW 裝置端語音模型，本站會優先啟用 processLocally 在裝置端辨識；否則才退回瀏覽器既有語音服務。本站會在瀏覽器自動結束一段辨識時重新啟動，直到你按「停止語音」，辨識候選再由本機工作詞彙重新排序。部分瀏覽器的備援語音服務可能需要網路；本站不保存音訊，也不把辨識文字送到雲端文字模型。

低耗能

內建的是小型工作溝通領域 GRU 模型，而不是數百 MB 的通用大型語言模型；另搭配安全／風險語料轉移權重。模型只在產生候選時短暫做本機排序，不進行伺服器推論或背景持續運算。
