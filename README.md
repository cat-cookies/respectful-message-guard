# 訊息溝通風險檢核器

一個不需要後端、可直接部署至 GitHub Pages 的純靜態網站。用途是協助管理人員、第一線工作者與服務人員，在傳送訊息前檢查職場霸凌、騷擾、跟蹤騷擾、對案家不禮貌及個資揭露風險，並產生可直接複製的較安全版本與修改理由。

## 主要功能

- 首頁先提供中華民國跟蹤、騷擾、職場霸凌與校園事件的法制分流介紹。
- 使用者確認後才進入檢核頁。
- 可勾選「在這個分頁關閉前不再顯示」，僅使用 `sessionStorage`，關閉分頁後失效。
- 在瀏覽器本機辨識辱罵、威脅、嘲諷、權勢壓迫、性或性別言詞、持續聯絡暗示、貼圖、表情符號、過度標點與對案家不禮貌表述。
- 遮罩明顯的身分證字號、電話、電子郵件、地址、病歷號或個案編號。
- 產生可複製版本，並於下方逐項說明不宜原因與適用法制風險。
- 不使用後端、資料庫、API、雲端模型、分析追蹤、Cookie、CDN 或第三方 JavaScript。

## GitHub Pages 部署

1. 建立新的 GitHub repository。
2. 將本資料夾內所有檔案上傳至 repository 根目錄。
3. 到 `Settings` → `Pages`。
4. `Build and deployment` 選擇 `Deploy from a branch`。
5. Branch 選擇 `main`，資料夾選擇 `/ (root)`，儲存。
6. 等待 GitHub Pages 完成部署。

不需要設定環境變數、存取權杖或後端網址。

## 本機預覽

在資料夾內執行：

```bash
python -m http.server 8000
```

再開啟 `http://localhost:8000`。

## 安全設計

- `Content-Security-Policy` 的 `connect-src` 設為 `none`，阻止頁面建立外部網路連線。
- 所有 CSS、JavaScript 與內容均為本地檔案。
- 原始訊息與結果只存在目前頁面記憶體；重新整理或關閉後消失。
- 唯一儲存項目是說明頁顯示狀態，且僅使用 `sessionStorage`。
